skyroute-planner/
├── backend/                                 núcleo de lógica en Python
│   ├── core/                                estructuras de datos base (SRP)
│   │   ├── graph.py                         clase Graph con lista de adyacencia implementada desde cero
│   │   ├── node.py                          clase Nodo (aeropuerto) con sus atributos

│   │   └── base_algorithm.py                interfaz abstracta común (ISP/OCP)
│   ├── services/                            lógica de negocio, una responsabilidad por servicio
│   │   ├── route_planner.py                 orquesta el cálculo de rutas según criterio elegido

│   │   ├── budget_manager.py                gestiona presupuesto, trabajos y umbral del 35%
│   │   ├── interruption_service.py          loquea aristas y recalcula ruta alternativa (R4)
│   │   └── report_service.py                genera el reporte final con totales y desglose (R5)
│   ├── models/                              entidades de dominio (puras, sin lógica)
│   │   ├── airport.py                       datos del aeropuerto: IATA, ciudad, hub, costos
│   │   ├── route.py                         tramo entre aeropuertos con aeronaves disponibles
│   │   ├── aircraft.py                      tipo de aeronave con costoKm y tiempoKm
│   │   ├── activity.py                      actividad (obligatoria/opcional) con duración y costo
│   │   ├── job.py                           temporal con tarifaHora y maxHoras
│   │   └── itinerary.py                     estructura que acumula el viaje completo del viajero
│   ├── interfaces/                          contratos abstractos (DIP/ISP)
│   │   ├── i_graph.py                       protocolo que debe cumplir cualquier implementación de grafo
│   │   ├── i_algorithm.py                   contrato abstracto para algoritmos de búsqueda
│   │   └── i_service.py                     interfaz base para servicios inyectables
│   ├── loaders/                             carga e inicialización del grafo desde JSON
│   │   ├── json_loader.py                   lee y valida el archivo JSON de la red aérea
│   │   └── graph_builder.py                 construye el grafo a partir de los datos cargados
│   ├── api/                                 capa REST (FastAPI)
│   │   ├── main.py                          punto de entrada de la aplicación FastAPI
│   │   ├── routes/                          endpoints agrupados por dominio
│   │   │   ├── graph_routes.py              endpoints de carga y consulta del grafo
│   │   │   ├── planner_routes.py            endpoints de planificación básica y avanzada
│   │   │   └── report_routes.py             endpoint para generar el reporte final
│   │   └── schemas/                         modelos Pydantic para validación de entrada/salida
│   │       ├── airport_schema.py            esquema de datos del aeropuerto para la API
│   │       └── route_schema.py              esquema de ruta y criterios de optimización
│   ├── utils/                               funciones auxiliares sin estado
│   │   ├── time_calculator.py               calcula tiempos de vuelo, alojamiento y alimentación
│   │   ├── cost_calculator.py               calcula costos por tramo según aeronave y distancia
│   │   └── validators.py                    valida restricciones de presupuesto, tiempo y repetición de nodos
│   └── config.py                            configuración global: valores por defecto de aeronaves e intervalos
│
